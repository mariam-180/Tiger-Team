## About The Project

Tigers Team Racing Simulator offers a dynamic and engaging platform to racing game aficionados. Users can learn about upcoming championships, reserve PCs for gaming sessions, and browse gaming products.-

## Features

- **Home**: Discover the thrill of racing simulation and what we offer.
- **Championship**: Stay updated on upcoming racing events and leaderboards.
- **Reservation**: Book a high-end PC for the ultimate gaming experience.
- **Products**: Explore our curated selection of gaming gear.

## Getting Started

To set up the project locally, follow these simple steps.

### Prerequisites

- npm
  ```sh
  npm install npm@latest -g

## Installation
1- Clone the repo
    git clone https://github.com/Mohammad-Alqadi/TigersTeamReact.git

2- Navigate to the project directory
    cd TigersTeamReact

3- Install NPM packages
    npm install

4- Start the project
    npm start

## Usage
After starting the project, you can navigate to http://localhost:3000 to view the app in the browser. You can make changes to the code; the page will reload if you make edits. You will also see any lint errors in the console.
